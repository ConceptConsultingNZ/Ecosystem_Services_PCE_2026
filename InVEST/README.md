# InVEST Configuration Files

This folder contains the configuration files used to run selected InVEST (Integrated Valuation of Ecosystem Services and Tradeoffs) models during the development of the ecosystem service layers.

The files are provided to document the model settings, input parameters, and workflow used in the project. They are included for transparency and reproducibility purposes and are not intended to be provided as ready-to-run model configurations.

The configuration files reference project-specific datasets, directory structures, and intermediate processing outputs that are not included in this folder, but can be found in the "workflow" release. The InVEST models themselves can be downloaded from https://naturalcapitalalliance.stanford.edu/invest/models.

These files should be interpreted alongside the accompanying technical documentation, which describes:

* The ecosystem service being modelled.
* The role of the InVEST model within the overall workflow.
* Input datasets and data dependencies.
* Key assumptions and parameter choices.
* Processing steps used to derive the final ecosystem service layers.

The technical documentation should be regarded as the primary source for understanding how InVEST outputs were used within the project and how they contributed to the final published ecosystem service datasets.
