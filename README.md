# Ecosystem Services 2026
Source repository for the development of New Zealand ecosystem service layers. The repository contains the reports, summary spreadsheet, Python code and InVEST model configuration files used to generate the final ecosystem service datasets published through the MfE Data Service.

Versioned releases provide the final ecosystem service raster datasets, associated reports and spreadsheets, as well as the processing scripts and intermediate files required to reproduce the modelling workflow.

We welcome reuse, adaptation, and further development of these resources. Please report any issues or suggested improvements through the repository’s Issues page.
