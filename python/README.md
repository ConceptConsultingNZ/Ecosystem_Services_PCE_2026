# Python Scripts
The scripts in this folder are provided for transparency and documentation purposes. They record the methods, processing steps, and analytical workflows used to develop the ecosystem service layers.

The scripts are not provided as a ready-to-run software package. They contain project-specific file paths, dependencies on intermediate datasets, and references to the local processing environment used during development.

Users seeking to understand how individual layers were generated, where specific scripts fit within the overall workflow, and the required input datasets should consult the accompanying technical documentation. The technical documentation is the primary reference describing the modelling framework, data sources, assumptions, processing sequence, and outputs.
